# AskTranslate 0.1.0

AskTranslate for Zotero 的首个独立版本，基于 windingwind 及贡献者的
[Translate for Zotero](https://github.com/windingwind/zotero-pdf-translate) 二次开发。

- 在划词翻译后继续向 AI 提问，结合选区、译文及文献标题和摘要理解当前段落。
- 支持 ChatGPT、自定义 GPT、AzureGPT、Claude 和 Gemini，支持流式回答、Markdown 和公式显示。
- 回答可复制、插入当前笔记或保存为新笔记。
- 使用独立名称、插件 ID、内部命名和设置空间，自动更新来自本 fork。
- 安装包附带 AGPL 许可证、上游署名、第三方声明及本地公式样式和字体。

安装：下载 **asktranslate.xpi**，在 Zotero「工具 → 插件 → 齿轮 → 从文件安装插件」中选择它。
安装前先停用原版 Translate 或旧的 AI 追问版，安装后重启 Zotero；此版本未验证与原版同时启用。
由于使用独立设置空间，需要在「设置 → AskTranslate」中重新配置翻译和模型服务。
已保存到 Zotero 的笔记会保留。
